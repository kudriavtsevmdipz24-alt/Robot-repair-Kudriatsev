# GDD — Robot Repair: Flood Run (v1.0)

## 1) Концепт
- **Жанр:** 2D top-down action/puzzle.
- **Платформа:** Windows x64.
- **Ціль гравця:** полагодити всіх зламаних роботів на рівні та дійти до перемоги.

## 2) Core Loop
1. Рух і читання загроз.
2. Уникнення шкоди.
3. Постріл шестернями (`C`) і лагодження ворогів.
4. Підбирання аптечок і контроль ризику.

## 3) Механіки
- **Базові:** рух, стрільба, шкода, невразливість після хіта, лікування.
- **Твіст (лаба 8):** `RisingWater` — вода піднімається в часі (`riseSpeed`, `maxHeight`, `damage` через Inspector).
- **Варіант префаба:** `RisingWaterFast` із вищою швидкістю підняття.

## 4) Рівень `MyLevel`
- **Ділянка 1:** вхід і знайомство з правилами.
- **Ділянка 2:** тиск твіста (підйом води + вороги/ризики).
- **Ділянка 3:** фінальна перевірка, комбінація загроз і ресурсів.

## 5) Інтерфейс (HUD)
- Смуга здоров'я.
- Лічильник полагоджених роботів.
- Діалогове вікно NPC.
- Екрани перемоги/поразки.

## 6) Зворотний зв'язок
- **Хіт по гравцю:** звук + короткий червоний спалах спрайта + спад смуги HP.
- **Підбирання аптечки:** звук + короткий зелений спалах + ріст HP.
- **Фікс ворога:** звук фікса + зміна стану ворога.

## 7) Сцени
- `StartScreen` — стартовий екран з кнопкою "Почати гру".
- `MyLevel` — основний рівень.

## 8) Технічні вимоги
- Windows 10/11 x64.
- Запуск гри: подвійний клік по `.exe` у збірці.

## 9) Ризики та відкладене
- Точне візуальне доведення стартового екрана можна покращити після додаткового плейтесту.
- Баланс `riseSpeed`/`maxHeight` потребує повторної перевірки на новому гравцеві.
