# Core Loop (Лекція 1)

1. Рухаюсь по ділянці та читаю загрозу попереду.
2. Уникаю шкоди (зони, контакт із ворогом) і шукаю кнопку для проходу.
3. Стріляю шестернями (`C`) і лагоджу ворогів.
4. Підбираю аптечки й повертаюсь у безпечний темп.

## Як твіст впливає на цикл

Твіст `TimedSwitch` підсилює кроки 1-2: гравець не може просто "чистити" ворогів у будь-якому порядку — потрібно натиснути плиту і встигнути пройти через двері до посиленого ворога.
