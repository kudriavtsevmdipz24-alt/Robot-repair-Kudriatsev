# Core Loop (Лекція 1)

1. Рухаюсь по ділянці та читаю загрозу попереду.
2. Уникаю шкоди (вода, зони, контакт із ворогом).
3. Стріляю шестернями (`C`) і лагоджу ворогів.
4. Підбираю аптечки й повертаюсь у безпечний темп.

## Як твіст впливає на цикл

Твіст `RisingWater` підсилює кроки 1-2: гравець не може довго стояти на місці, бо вода піднімається і перетворює "чекання" на ризик.
