# Core Loop (Лекція 1)

1. Рухаюсь по ділянці та читаю загрозу попереду.
2. Уникаю шкоди (зони, контакт із ворогом) і шукаю кнопку для проходу.
3. Стріляю шестернями (`C`) і лагоджу ворогів.
4. Підбираю аптечки й повертаюсь у безпечний темп.

## Як твіст впливає на цикл

Плита відкриває короткий маршрут до фінальних патрулів на 3,5 с. Поки триває відлік, гравець переводить увагу з прицілювання на рух. Після закриття дверей можна повернутися до плити й повторити спробу або піти верхнім обходом через пастку.
