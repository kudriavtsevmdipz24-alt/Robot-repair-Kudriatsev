# Перевірка Robot Repair: Timed Gate

| Ситуація | Очікуваний результат |
|---|---|
| Кнопка «Почати гру» | Стартує `MyLevel` із повним здоров’ям і п’ятьма зламаними роботами. |
| Підійти до NPC і натиснути X | Репліка пояснює ремонт, плиту і шлях через двері. |
| Спробувати пройти прямо до натискання плити | Зачинені двері блокують рух і шестерні. |
| Стати на плиту й бігти праворуч | Плита зеленіє, HUD показує відлік, крізь отвір можна пройти. |
| Затриматися на плиті довше 3,5 с | Двері зачиняються. Новий вхід на плиту запускає відлік. |
| Пройти верхнім обходом | Прохід відкритий, пастка завдає шкоди. |
| Наступити на пастку й узяти аптечку | Здоров’я падає і відновлюється, HUD показує зміни, лунають різні звуки та видно спалахи. |
| Влучити в усіх роботів | Лічильник показує 5 / 5 і з’являється екран перемоги. |
| Втратити все здоров’я | З’являється екран поразки. Приблизно за 4 с рівень перезапускається. |
| Розпакувати й запустити Windows .exe | Стартовий екран відкривається без Unity Editor. |

## Контрольні проходження

Unity 6000.3.23f1, Play Mode. Маршрут пройдено автоматизованим клавіатурним вводом з рухомими патрулями й пострілами за штатними правилами гри. У всіх трьох проходженнях лічильник дійшов до 5 / 5 і з’явився екран перемоги.

| Маршрут | Ігровий час | Здоров’я на фініші |
|---|---:|---:|
| Прямо через двері | 11,5 с | 5 / 5 |
| Через двері після завершення відліку й повторної активації | 16,3 с | 4 / 5 |
| Верхнім обходом | 13,5 с | 4 / 5 |

Окремо перевірено, що стояння на плиті не тримає двері відкритими, закриті двері блокують рух, пастка знімає здоров’я, аптечка його відновлює, а рівень після поразки повертається до початкового стану. Час автоматизованих проходжень відображає маршрут без пауз на орієнтацію. Для оцінки курсової цілі 60–90 с потрібен ручний плейтест із новим гравцем.

Готовий ZIP розпаковано в окрему теку. Windows x64 Player запустився поза Unity Editor та ініціалізував Direct3D 11 і Input System.
