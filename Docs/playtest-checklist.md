# Плейтест-чекліст (Лекція 13)

## Перевіряємо твіст (лаба 8)

- Чи помітив гравець, що вода рухається, без підказки.
- Чи зрозумів, що треба прискоритись і не стояти внизу.
- Чи можна пройти рівень, навіть якщо один раз помилився на твісті.

## Перевіряємо полішинг (лаба 9)

- Хіт по гравцю: є звук + видимий сигнал + спад HP.
- Підбирання аптечки: є звук + видимий сигнал + ріст HP.
- HUD читається на відстані (лічильник і смуга не губляться на фоні).
- Стартовий екран веде в `MyLevel`, перемога/поразка ведуть до зрозумілого перезапуску.
- Windows `.exe` проходиться від старту до перемоги поза Unity Editor.
